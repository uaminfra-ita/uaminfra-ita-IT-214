# Figuras

Coloque nesta pasta somente figuras necessárias ao artigo. Prefira gráficos e
diagramas produzidos pelo próprio autor. Para materiais de terceiros, registre
a fonte, a autoria e a licença e confirme que a redistribuição é permitida.

Use nomes curtos, sem espaços e descritivos, como `mapa-vertiportos.png`.
